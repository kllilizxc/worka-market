# Worka market

Worka reads `catalog-v4.jsonl` as a searchable directory of GitHub packages. Each line identifies a note or desktop by its stable listing ID, display metadata, repository and folder. Open a listing to resolve the latest stable release and preview the package. A repository with no stable release tags uses its default branch.

Authors publish versioned code and prebuilt notes in their package repositories. Publishing a new version needs no catalog change. To list an item or edit its display text, submit a change to its row.

The v3 and earlier catalog files remain for released Worka clients. Remove them after the next Worka release and the maintainer's rollout decision.
