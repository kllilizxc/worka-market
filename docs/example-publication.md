# Example notes

The checklist, counter and greeting packages live in `examples/<name>`. Each contains its source, note manifest and matching prebuilt files. Release the examples with a root semver tag on the tested commit. A change to a sibling folder does not require users of an unchanged note to update. Catalog-only edits do not create a package release.

The proposed initial release tag is `v1.0.1` on `826b76f6`. Tagging requires maintainer approval.
